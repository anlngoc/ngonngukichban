Cosmetics Shop - Node.js

Giao diện cửa hàng mỹ phẩm dựa theo ảnh mẫu, xây dựng bằng:

Node.js

Express.js

EJS

HTML/CSS

Hình ảnh: ![Giao diện](./public/images/Screenshot.png)


Chạy project
npm install
npm start


Sau đó mở:

http://localhost:3000


Trong quá trình code có thể dùng:

npm run dev
